# Explicit overrides of firm defaults

Only list a deviation from a FIRM default here, and give the reason. If it
conflicts with a firm/security/legal rule, the firm rule still wins.

- **Override:** (what you do differently)
  **Reason:** (why)

Example:
- **Override:** I draft my client updates in English even though the firm default is Hebrew.
  **Reason:** My clients on the Levi and Cohen deals are English-speaking.
